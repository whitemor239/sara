# TastyTum brand & asset notes

- **Wordmark:** the existing Persian text wordmark, rendered in `templates/base.html` (`تِیستی‌توم`). There is no standalone logo file in the project.
- **Palette:** flour/paper surfaces, cocoa text, muted berry accent, and sage for food labels. Keep this warm handmade palette; avoid metallic gradients and decorative badges.
- **Typography:** local Vazir font at `static/bakery/Vazir-Regular.woff2` for Persian UI and headlines.
- **Hero image:** `static/bakery/tart-sample.webp`, cropped from the supplied `media/products/Create-one-polished-photorealistic-NARON_3.png`. The source contains an unrelated NARON wordmark in its upper area; the crop excludes it and the page labels the tart as a sample image. Do not use the embedded NARON mark as TastyTum identity or attach this image to a specific menu item without verification.
- **Product photography:** upload confirmed product-specific photographs and alt text through Django admin. The sample hero visual is not a substitute for individual menu photos.
